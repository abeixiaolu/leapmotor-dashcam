# 零跑记录仪

本地 React + React Bits 工作台，已适配本机零跑 U 盘的 `driverecord` / `sentinel` 原始 `.h264` 四路合成录像。启动后自动扫描，无需选择文件夹。

## 打开

在这台 Mac 上双击 `启动零跑记录仪.command`，会打开本地页面；若服务已经运行则直接打开。保持启动窗口运行。也可执行：

```sh
vp install
vp run start
```

本机需要 FFmpeg / FFprobe（已安装在 `/opt/homebrew/bin/`）。目前自动发现使用 macOS `/Volumes`，不支持部署成远端纯静态网页后访问电脑 U 盘。

## 使用

- 插入 U 盘后最多约 8 秒自动发现；行车与哨兵分开浏览，可以搜索日期或时间。
- 默认一路大画面、右侧三路预览，点击任一小画面切换主视角；也可切换四宫格。
- 统一播放、暂停、0.25–4× 倍速、拖动进度、前后 10 秒、前后片段。
- 任一路全屏，全屏内保留播放与进度控制。
- 鱼眼校正默认开启，95° 视野；可在 60–130° 调节或关闭查看完整原始画面。更大的视野带来更明显的边缘透视拉伸。

## 真实格式适配

此 U 盘为单个 1920×1536 AVC/H.264 裸流，四象限依次是：左上前、右上后、左下左、右下右。已通过行驶场景中道路、车辆和隔离带的位置核对。每路原始尺寸 960×768。

应用在电脑缓存目录封装 MP4，不重新压缩 H.264 画面。裸流自身的默认解码时间信息不可靠；读取真实帧时间信息修正时长，无法取得时回退到 25fps。四路从同一个解码视频帧采样，避免四个播放器独立追时造成漂移。

去畸变使用逐象限的等距鱼眼反向采样、像素等比镜头半径，限制采样范围避免相邻画面串入。这是适合此录像的近似显示校正，不是依据厂家镜头内参的精密测量标定。原始完整画面随时可通过关闭校正查看。

## 只读与隐私

- U 盘仅用于目录枚举、文件状态检查和读取；不写入、不删除、不移动、不改名。
- MP4 缓存和处理中间文件只在电脑系统临时目录中，程序会清理过期缓存。
- 本地服务只接受本机同源请求，文件通过不透明 ID 访问，不接受任意文件路径。
- 无上传服务。拔出 U 盘后，下一次自动扫描会清空对应列表与播放器。
- 操作系统自身的可移动磁盘后台行为不属于网页可控制范围。
