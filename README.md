# 零跑记录仪

纯浏览器运行的零跑行车记录仪播放器，使用 Vite+、React 和 TanStack Router。支持 `driverecord` / `sentinel` 下的原始 `.h264` 四路合成录像。只需部署静态网页，不需要 Node 服务端或安装 FFmpeg。

## 使用

1. Mac 本机双击 `启动零跑记录仪.command` 打开，插入 U 盘后自动扫描录像，刷新无需重新选择；每 4 秒检查一次插拔。
2. 静态网页、非 iPhone 设备或远程访问时，点击「选择 U 盘/文件夹」，在系统选择器的「浏览」中进入 U 盘或录像目录，点右上角「打开」。网页自动整理所选目录及子目录中的 `.h264`，按日期与行车／哨兵分类，无需逐个选择文件。不支持目录选择时使用「多选录像文件」。手动选择成功后，本次页面停止 Mac 磁盘自动扫描，避免覆盖所选内容。
3. 按日期与行车／哨兵分类选择片段，浏览器在后台封装后播放。

录像不会上传。Mac 本地服务仅扫描 `/Volumes` 下的 `driverecord` / `sentinel` 录像目录，点开片段时才读取内容，接口仅允许本机访问。系统选择器中的「上传」表示将文件交给网页本地读取。静态部署仍受浏览器权限限制，刷新后需要重新选择文件，不能自动扫描磁盘。

iPhone（包括 Safari 和 Chrome）仅提供「多选录像」，每次选择 1–10 个 `.h264` 文件，不提供整个 U 盘或文件夹导入。请在「浏览」中进入 U 盘的录像目录，逐个勾选后点「打开」。超过 10 个文件或返回文件夹内容时，网页拒绝整批选择，保留原列表，不截取前 10 个，也不会开始视频处理。每次成功选择替换当前列表，不累计导入；刷新后需重新选择。没有目录信息的文件默认归为行车。

iOS 系统文件选择器不提供网页可用的「隐藏全选」或「最多勾选 10 个」接口；页面提示不要全选，并在系统返回文件后强制校验数量，无法阻止系统在返回前导入已勾选文件。建议先选择 1–2 段验证播放。桌面浏览器保留原有文件夹导入。

- 四路同步播放；顶栏切换主视角／四宫格，点击小画面切换主视角。
- 支持暂停、0.25–4× 倍速、进度拖动、前后十秒、上一段／下一段。
- 全屏保留完整播放工具栏，切换片段时保持全屏。
- 支持鱼眼校正、视野和强度设置；只改变显示，不修改录像。

## 开发与静态部署

```sh
vp install
vp run dev
```

```sh
vp run build
```

将生成的 **`dist/` 整个目录**部署到静态托管即可。使用相对资源路径和 Hash 路由（`#/recordings/<ID>`），支持子目录部署，无需后端 API 或 SPA 地址重写。不要直接双击 `index.html`，需通过 HTTP(S) 静态托管访问；正式部署建议 HTTPS。

部署必须包含 `assets/` 中的 JS、Worker 和 WASM 文件，`.wasm` 建议配置 `application/wasm` MIME 类型。单线程处理不依赖跨源隔离响应头或 SharedArrayBuffer。播放组件随构建产物一起部署，不从第三方 CDN 加载；首次播放按需下载约 32 MB WASM（开启 gzip 后约 10 MB），后续可由浏览器 HTTP 缓存复用。

本地预览生产构建：

```sh
vp run preview
```

`启动零跑记录仪.command` 提供 Mac 本地自动扫描入口；`vp run dev` 和 `vp run preview` 同样支持。静态部署不包含本地扫描服务，使用手动文件选择。

## 视频处理与限制

原始视频为 AVC/H.264 裸流，四象限依次为前、后、左、右。浏览器通过 ffmpeg.wasm 的 WorkerFS 按需读取 File，在后台 Worker 中无损封装为 MP4，不重新编码画面。

读取零跑 SEI 帧时间戳，并核对时间戳数量与视频包数量；匹配时使用记录的平均帧率修正时长，否则回退到 25fps。显式设置 MP4 时间基，并校正 H.264 码流中的时钟和 Level 标记，避免异常时间信息造成过快播放或过高的 Level 标记影响兼容性。保持视频像素不变，不转码。四路画面从同一个解码视频帧采样，保持同步。

单段文件限制为 512 MB；手机可能在更小的文件上遇到内存限制。当前仅保留正在播放片段的内存缓存，切换片段会终止旧处理任务、释放 Worker 和播放地址，再次打开会重新封装。无需浏览器磁盘缓存权限。

现代浏览器需支持 WebAssembly、Worker、WebGL 和 H.264 解码。目录选择兼容性依设备而异，提供多文件选择作为备用入口。鱼眼校正是近似显示校正，不是厂家内参标定。

## 验证

```sh
vp check
vp test
vp test tests/browser-remux.test.ts
vp run build
```

测试覆盖文件分类与排序、SEI 时间戳、异常时间基、WASM 无损封装后的时长与逐帧像素、镜头采样和设置。封装测试直接运行与浏览器相同的 WASM，无需本机 FFmpeg。真实 U 盘录像仅用于本机验收，不纳入版本库。
